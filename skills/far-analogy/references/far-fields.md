# Far-field map: obstacles each field is good at overcoming
| Field | Obstacles it beats | Typical tools |
|---|---|---|
| Statistical physics | local minima; collective behavior from local rules; phase transitions | annealing, renormalization, mean field |
| Thermodynamics | one-way quantities; efficiency limits | entropy, second-law inequalities |
| Economics, mechanism design | selfish agents, hidden information; scarce allocation | prices as duals, auctions, equilibria |
| Control theory | unstable feedback; keep state in a safe region | Lyapunov functions, feedback, observers |
| Evolutionary biology | huge gradient-free search; keeping diversity | selection, mutation, island populations |
| Ecology | resource competition; multi-species balance | predator–prey models, niche partitioning |
| Immunology | recognizing novelty in huge spaces; memory | clonal selection, immune memory |
| Information theory | noisy channels; compression; hard limits | error-correcting codes, entropy, lower bounds |
| Cryptography | proving "impossible" against bounded adversaries | reductions, pseudorandomness |
| Linguistics | nested structure; ambiguity | grammars, parse trees |
| Sports tactics | multi-agent coordination under hard rules; phase changes | roles, formations, pressing |
| Architecture, urban planning | overlapping constraints; modularity | pattern languages, layering |
| Epidemiology | spread over networks; minimal intervention | SIR models, herd-immunity thresholds |
| Materials science | optimal structure under load; defect propagation | topology optimization, homogenization |
| Power systems | cascading failures; protection coordination | breakers, selective protection, N-1, load shedding |
After each campaign, add the obstacle a field actually solved.
